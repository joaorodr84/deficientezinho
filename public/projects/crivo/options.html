Options

The ones you are most likely to want

crivo run --help lists everything.

OptionWhat it does
-n, --candidates NImages shown per keyword, 3 to 200. The default is 5.
--size WxHOutput size. The default is 512x512.
--mode crop|pad|fitcrop fills the size and cuts the overflow; pad fits inside and fills the rest; fit fits inside and stops, so sizes are not uniform.
--format png|jpeg|webpOutput format. The default is png, which keeps transparency.
--background #RRGGBBThe fill for pad, and what a JPEG is flattened onto.
--term-templateWrap every search term, for example '{term} icon' to find icons.
--multipleAllow more than one image per keyword (apple.png, apple-2.png).
-o, --output ZIPWhere to write the zip. It is not replaced unless you pass --overwrite.
--no-browserPrint the address instead of opening it.

Pixabay's own search filters are options too: image type, orientation, category, colours, minimum width and height, safe search, editor's choice, order and language.

Pausing and resuming

Close the laptop, carry on later

Your picks are saved as you make them. Close the terminal or press Ctrl-C, then come back with:

crivo run --resume

Resuming does not search again for anything already searched: the page comes back as you left it. Starting a new run while an unfinished session is saved is refused, so an afternoon of picking is not thrown away by accident. Pass --restart when you mean to start over.
