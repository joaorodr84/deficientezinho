Crivo

A hundred words in. One picture for each, out.

Give Crivo a list of keywords. It searches Pixabay for each one, shows you the candidates in your browser, and hands your picks back resized to one size in a zip.

pipx install crivo
crivo run keywords.txt
Why it exists

The choosing is the only part that needs you

Finding one picture for each of a hundred words, all the same size, is mostly searching, downloading, resizing and packaging. Crivo does those. You only pick. The name is Portuguese for sieve.

About this build

Version 0.2.0, on PyPI

A command-line tool for Python 3.10 or newer, on Windows, macOS and Linux. It has been run against the live Pixabay API on Windows; the same run has not yet been made on macOS or Linux, so expect a rough edge or two there.
